# ⚽ Arsenal Football Analytics Dashboard

## 📌 Project Overview

This project is a football data analytics project focused on analyzing Arsenal FC's performance during the 2025/2026 season.
The objective is to transform raw football data into meaningful insights using data processing, SQL analysis, and interactive visualization.
The project covers:
- Team performance analysis
- Match results analysis
- Player statistics analysis
- Goal and assist contribution analysis
- Player efficiency evaluation
The final result is an interactive Power BI dashboard designed to provide a clear view of Arsenal's performance.

# 🎯 Objectives

The main objectives of this project are:
- Collect and organize football data
- Clean and prepare datasets for analysis
- Store structured data in PostgreSQL
- Perform analytical queries using SQL
- Create meaningful football performance metrics
- Build an interactive dashboard with Power BI
- Develop a complete Data Analytics workflow
